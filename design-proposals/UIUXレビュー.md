## 実装担当向け 作業指示リスト

### P0（公開前必須）

- [ ] パーティ申込リンクを本番仕様にする（第1回は Formzu URL、未作成なら「準備中」。`href="#"` の見た目ボタンは廃止）
- [ ] 第2・3回は「日程調整中」等にし、申込ボタンは出さない／無効化
- [ ] モバイルナビの代替を実装する（現状 720px 以下で `.nav` 消滅のみ）
- [ ] ナビ「役員」の飛び先を修正（`#profile` → `#officers`、または文言を「理事長」に）

### P1（早めに）

- [ ] ヒーローの情報量を削減（ロゴ → 名称 → キャッチ1行 → リード1文 → CTA）
- [ ] ヒーロー CTA の主／副を一般読者向けに再配置
- [ ] ヒーロー画像を本番素材に差し替え（Unsplash 仮画像依存を解消）
- [ ] 研究・実績に既刊・主要論文の短い一覧（3〜5件）を追加
- [ ] `:focus-visible` をボタン・リンク・`summary` に追加

### P2（余裕があれば）

- [ ] 理事長プロフィールを段落分割または見出し付きに
- [ ] `h1` をブランド名にし、キャッチはサブ扱いに
- [ ] 外部リンクに「外部／新しいタブ」の示唆を追加
- [ ] 本番ではテーマ切替 `chooser` を外し `mori` 固定。sticky の `top` を再調整
- [ ] ワードマークの `href="#"` を正しいトップ／先頭リンクに

### 完了条件

- [ ] スマホ幅で研究所紹介・パーティ・問い合わせへ辿れる
- [ ] 第1回申込が実 URL、または明確な「準備中」
- [ ] 第2・3回を申込可能と誤認しない
- [ ] ナビ「役員」の着地が期待どおり
